## 摘要
全切片图像分析通常被建模为多实例学习（MIL），其中实例特征经过上下文更新并聚合为切片表示，我们将这一过程称为切片编码动态。近年来，选择性状态空间模型（SSM）因其长序列建模能力和线性复杂度而成为有前景的MIL架构。然而，现有基于SSM的MIL方法在MIL过程中仅依赖视觉特征。同时，在大规模WSI中，稀疏的诊断决定性区域被大量无关信息包围，这种纯视觉驱动的选择性动态可能错误分配状态更新和读出，导致演化的SSM状态在长扫描轨迹中积累与任务无关的证据，并稀释关键的诊断线索。在本文中，我们提出了知识感知隐状态调制架构（KHiM-Mamba），它创新性地利用显式知识先验调节Mamba核心的选择性状态空间机制，引导切片编码动态朝着具有诊断意义的证据积累方向发展。具体而言，我们重新设计了原始SSM层，在隐状态演化过程中执行知识调制操作，从而指导每一步编码中从隐状态积累和检索哪些视觉证据。此外，我们还引入了一个局部自适应词汇检索模块，该模块利用大语言模型为每个图像块分配细粒度、组织特异性的语义描述，从而在不同任务中实现精确调制。在涵盖4个任务的11个公开基准上的实验表明，KHiM-Mamba始终取得了最先进的性能。

## Abstract
Whole slide image analysis is commonly formulated as multiple instance learning (MIL), where instance features are contextually updated and aggregated into a slide representation, a process we term slide encoding dynamics. Recently, selective state-space models (SSM) have emerged as promising MIL architectures due to their long-sequence modeling capability and linear complexity. However, existing SSM-based MIL methods rely solely on visual features during MIL. Meanwhile, in large-scale WSIs, where sparse diagnostically decisive regions are surrounded by abundant irrelevant information, such purely vision-driven selective dynamics can misallocate state updates and readouts, causing the evolving SSM state to accumulate task-irrelevant evidence and dilute critical diagnostic cues over long scan trajectories. In this work, we propose the Knowledge-Aware Hidden-State Modulation architecture (KHiM-Mamba), which innovatively regulates Mamba's core selective state-space mechanism with explicit knowledge priors, steering slide encoding dynamics toward diagnostically meaningful evidence accumulation. Specifically, we redesign the original SSM layer to perform knowledge modulation operations during the evolution of hidden states, thereby guiding what visual evidence is accumulated and retrieved from the hidden state at each encoding step. Furthermore, we additionally introduce a local-adaptive vocabulary retrieval module that uses large language models to assign each patch fine-grained, tissue-specific semantic descriptions, enabling precise modulation across diverse tasks. Experiments on 11 public benchmarks across 4 tasks show that KHiM-Mamba consistently achieves state-of-the-art performance.

- **研究背景**：全切片图像（WSI）分析通常建模为多实例学习（MIL），其核心是“切片编码动态”——即实例（patch）特征之间的上下文交互，以及最终聚合为切片级表示的过程。

- **已有 VLM-MIL 的不足**：现有引入语言知识的 MIL 方法通常把语言作为“外围组件”——要么在编码前做 patch 选择，要么在编码后做辅助监督，**没有直接干预核心的切片编码动态**。
- **本文整体含义**：提出 KHiM-Mamba，直接把病理语言知识注入 Mamba 的选择性状态空间机制中，通过调节隐状态的写入与读出，使切片编码过程主动围绕诊断相关证据展开。

## 2. 论文提出的方法论

### 2.1 核心思想

- 将语言衍生的病理知识先验注入到 Mamba 的核心 SSM 动态中，而不是将其作为外围模块。
- 具体做法是调节 SSM 中的两个输入依赖投影矩阵：
  - **\(\mathbf{B}_t\)**：控制当前 patch 信息如何写入隐状态。
  - **\(\mathbf{C}_t\)**：控制累积上下文如何从隐状态中读出。
- 通过“写入调制”和“读出调制”，让模型在每个编码步骤上都以显式语义为指导，决定哪些视觉证据被积累、哪些被检索。

### 2.2 知识感知隐状态调制（KHiM）

- 给定 patch 特征序列 \(X = \{x_t\}_{t=1}^T\)，每个 patch 对应一个语言嵌入 \(\mathbf{e}_t\)。
- 使用一个共享 MLP 将 \(\mathbf{e}_t\) 映射为低秩系数向量：
  \[
  [\boldsymbol{\alpha}_B^t; \boldsymbol{\alpha}_C^t] = \text{MLP}(\mathbf{e}_t) \in \mathbb{R}^{2r}
  \]
  其中 \(r \ll N\)，\(N\) 为 SSM 状态维度。
- 将低秩系数与可学习基矩阵 \(\mathbf{W}_B, \mathbf{W}_C \in \mathbb{R}^{r \times N}\) 组合，得到增量：
  \[
  \Delta B_t = \boldsymbol{\alpha}_B^t \mathbf{W}_B,\quad
  \Delta C_t = \boldsymbol{\alpha}_C^t \mathbf{W}_C
  \]
- 通过残差方式调制原始投影：
  \[
  \tilde{B}_t = B_t + \gamma \Delta B_t,\quad
  \tilde{C}_t = C_t + \gamma \Delta C_t
  \]
  其中缩放因子 \(\gamma\) 初始化为较小值，使训练开始时接近原始 Mamba，逐渐引入语言影响。
- 最终语言条件下的 SSM 递归为：
  \[
  h_t = \bar{A}_t h_{t-1} + \Delta_t \tilde{B}_t x_t,\quad
  y_t = \tilde{C}_t h_t
  \]
- 这样设计不改变 SSM 的时间动态或衰减行为，只重塑信息注入与读出通道，因而优化更稳定。

### 2.3 局部自适应词汇检索模块

- **任务特定概念集构建**：用大语言模型（LLM）根据下游任务定义生成最相关的组织类型概念集 \(\mathcal{T} = \{T_1, \dots, T_M\}\)，并为每个概念生成细粒度、组织特异的形态与病理描述集 \(\mathcal{S}_m\)；同时定义一个粗粒度病理描述集 \(\mathcal{S}_{\text{coarse}}\) 作为回退。
- **置信度门控概念路由**：用 CONCH 模型计算每个 patch 视觉嵌入与组织概念文本嵌入的余弦相似度 \(a_{t,m}\)，选择最相似概念 \(m^*\)。
  - 仅当 \(a_{t,m^*} > \tau_{\text{sim}}\) 且与第二候选的间隔 \(>\tau_{\text{margin}}\) 时，接受该概念并采用 \(\mathcal{S}_{m^*}\)。
  - 否则回退到粗粒度描述集 \(\mathcal{S}_{\text{coarse}}\)。
- **语言嵌入构建**：用 CONCH 文本编码器对选定描述进行编码并聚合，得到 patch 级语言表示 \(\mathbf{e}_t\)，再输入到低秩调制机制中。
- 这种“局部自适应”设计使每个 patch 获得与其组织类型匹配的语义先验，而非所有 patch 共享同一固定词汇。

## 6. 论文的主要结论与发现

- KHiM-Mamba 在**全部 11 个公开基准、4 类任务**上取得最优表现：
  - 癌症亚型：BRACS-7 ACC 0.5874 / AUC 0.8746；BRACS-3 ACC 0.8165 / AUC 0.9074；TCGA-BRCA ACC 0.9330 / AUC 0.9559。
  - 生存预测：平均 C-Index 0.7394，超过最佳对比方法 2DMamba（0.7163）。
  - 跨中心泛化：CAMELYON17 平均 AUC 0.9184，超过 TransMIL（0.8957）。
  - 少样本：8-shot ACC 81.45% / AUC 93.48%，显著优于 MOC。
- **消融发现**：
  - \(\Delta B\) 单独使用即可带来稳定提升；\(\Delta C\) 单独使用提升有限，但与 \(\Delta B\) 联合使用时显著互补，平均 AUC 从 0.8632 提升到 0.9127。
  - 局部自适应词汇检索优于类标签和固定提示词；不同 LLM 生成词汇的性能差异不大，说明方法对 LLM 选择具有鲁棒性。
- **可视化与效率**：
  - 知识调制后 patch 注意力更集中于真实肿瘤区域，背景抑制更明显。
  - KHiM-Mamba 参数量 2.22M，低于多数 Mamba 变体；在 1,000 / 5,000 patch 序列下推理时间分别为 2.50 ms / 5.79 ms，保持线性效率。

## 7. 优点

- **方法创新性强**：首次将语言知识直接注入 Mamba 的隐状态演化过程，而不是把语言作为外部提示或监督信号。
- **设计合理且稳定**：低秩残差调制不改变 SSM 动态，缩放因子从小值初始化，训练更稳定。
- **局部自适应词汇**：采用置信度门控路由，为不同 patch 提供组织特异语义，比全局固定词汇更精细。
- **实验充分**：覆盖分类、生存预测、域泛化、少样本、效率、可视化、多组消融，对比方法多且新。

- **兼顾性能与效率**：在提高准确率的同时保持 Mamba 的线性复杂度和较低参数规模。
