## 摘要
准确的细胞检测与分类对病理分析至关重要，直接影响诊断准确性和治疗规划。为了捕捉肿瘤微环境中超越视觉外观的复杂细胞相互作用，一些方法采用图神经网络对细胞核间的空间和关系模式进行建模，取得了有希望的结果。然而，这些方法通常采用两阶段范式：先进行视觉提取再进行关系建模，这需要对每个阶段分别调优，从而增加了流程的复杂性，并阻碍了端到端的联合优化。在本文中，我们提出了一种端到端的细胞检测与分类框架，该框架联合建模图像块级视觉表示和实例级交互，其中包含一个动态图构建模块和一个实例感知图网络。具体而言，图构建模块利用从图像块级特征中得到的可学习查询作为细胞实例表示，动态构建图结构，并通过融合特征相似性和空间距离来定义邻接关系。实例感知图网络执行自适应实例过滤和特征重组，将它们聚合到细胞图上的拓扑潜在状态中，以进行由视觉线索驱动的选择性状态空间转换，融合外观和关系证据。在多个具有不同染色方案的细胞和细胞核检测数据集上进行评估时，我们的方法在检测和分类性能上均显著优于现有方法。代码将发布在 https://github.com/RuochenLiu23/IGM。

## Abstract
Accurate cell detection and classification are crucial for pathological analysis, directly affecting diagnostic accuracy and treatment planning. To capture complex cellular interactions beyond visual appearance within the tumor microenvironment, several approaches have employed graph neural networks to model spatial and relational patterns among cell nuclei, yielding promising results. However, these methods typically adopt a two-stage paradigm of visual extraction followed by relational modeling, which necessitates separate tuning for each stage, thereby increasing pipeline complexity and hindering end-to-end joint optimization. In this paper, we propose an end-to-end framework for cell detection and classification that jointly models patch-level visual representations and instance-level interactions, which incorporates a dynamic graph construction module and an instance-aware graph network. Specifically, the graph construction module dynamically builds the graph structure using learnable queries derived from patch-level features as cell instance representations, with adjacency defined by integrating feature similarity and spatial distances. The instance-aware graph network performs adaptive instance filtering and feature reorganization, aggregating them over the cell graph into a topological latent state for a selective state-space transition driven by visual cues, fusing appearance and relational evidence. When evaluated on multiple datasets with different staining protocols for cell and nucleus detection, our method significantly outperforms existing approaches in both detection and classification performance. The code will be released at https://github.com/RuochenLiu23/IGM.

## 2. 论文提出的方法论

论文框架由三个核心组件构成：**查询特征学习网络**、**动态图构建模块（DGC）** 和 **实例感知图网络（IGN）**。

### 2.1 查询特征学习网络

- 使用 ResNet-50 作为骨干网络提取多尺度特征，经 Transformer 编码器和多尺度可变形注意力获得增强的视觉表示 \( f'_{enc} \)。
- 从特征图中选取高质量候选框，提取锚点特征，并与可学习查询向量相加，得到查询嵌入 \( Q_{enc} \)。
- Transformer 解码器迭代更新查询特征和参考点，输出查询特征 \( Q \) 和中心坐标 \( P \)，为后续图构建提供实例级表示和空间位置。

### 2.2 动态图构建模块（DGC）

- 将查询作为图节点，定义查询距离函数 \( s_{ij} \)，融合：
  - **空间距离**：基于参考点欧氏距离的指数衰减 \( s^p_{ij} = \exp\left(-\frac{\|p_i - p_j\|^2}{2\bar{d}}\right) \)；
  - **特征距离**：基于查询特征 L2 归一化后的余弦相似度 \( s^f_{ij} \)；
  - 综合距离：\( s_{ij} = \alpha \cdot (1 - s^p_{ij}) + (1-\alpha) \cdot (1 - s^f_{ij}) \)，其中 \( \alpha \) 为权重（论文取 0.5）。
- 基于综合距离使用 KNN 建立邻接矩阵 \( M \)，图结构随训练动态更新，使拓扑与特征相互促进。

### 2.3 实例感知图网络（IGN）

IGN 包含两个协同组件：**实例感知图学习（IGL）** 和 **拓扑结构化状态空间（TSS）**，并配合 **上下文引导状态编码（CGSE）**。

#### IGL：
- **选择性特征重组（SFR）**：  
  对节点特征 \( x_i \in \mathbb{R}^d \)，通过 CGSE 动态生成的门控矩阵 \( \Delta_i \) 和方向矩阵 \( B_i \)，计算隐藏状态 \( h_i = (\Delta_i \odot x_i) \otimes B_i \)。该操作过滤冗余查询，并将相似节点映射到相近方向、不相似节点映射到近正交方向，从而提升特征判别性。
- **方向性图聚合**：  
  对重组后的特征进行对称归一化图聚合 \( \hat{h} = D^{-1/2}(M+I)D^{-1/2}h \)，利用邻接关系将邻居状态叠加，得到抗噪的拓扑结构表示。语义不一致的邻居因近正交而不会污染目标节点状态。

#### TSS：
- 将图聚合得到的拓扑表示 \( \hat{h} \) 作为潜在状态，以查询视觉特征 \( x \) 驱动状态更新：  
  \( H = \bar{A}\hat{h} + \bar{B}x \)，\( y = C H \)。
- 使用零阶保持（ZOH）离散化连续状态空间模型，使 \( \bar{A} \)、\( \bar{B} \) 由 CGSE 生成。
- TSS 以线性复杂度融合全局关系与外观证据，并通过残差连接输出最终特征 \( Q_f = y + D x_0 \)。

#### CGSE：
- 从所有查询特征中提取实例级上下文，动态生成状态空间参数 \( A, B, C, \Delta \)。
- \( A \) 基于 HiPPO-LegS 初始化，全局共享；\( B \)、\( C \) 由线性变换学习；\( \Delta \) 通过 Softplus 和低秩结构控制参数量。

## 7. 优点

- **端到端联合优化**：打破两阶段范式，图构建与检测在统一目标下训练，避免误差传播和分阶段调参。
- **动态图构建**：融合空间与特征相似度，图拓扑随训练动态演化，适应不同细胞分布。
- **实例感知与抗噪设计**：SFR 选择性重组、方向性图聚合使不相关节点近正交，无需显式剪枝即可抑制冗余查询。
- **线性复杂度全局建模**：TSS 基于选择性状态空间模型，在保持全局感受野的同时避免二次复杂度，适合大规模细胞图。
- **实验全面**：覆盖多数据集、多染色、多方法比较，消融和超参数分析充分，代码开源。
