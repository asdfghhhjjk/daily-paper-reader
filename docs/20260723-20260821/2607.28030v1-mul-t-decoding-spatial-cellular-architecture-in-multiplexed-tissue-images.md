## 摘要
理解多重成像中的组织空间结构需要对细胞表型及其空间背景同时建模。现有方法通常依赖手工特征，例如标志物强度统计或细胞类型比例，这些特征在标志物组合异质的队列中往往难以扩展或泛化。我们提出 MUL-T，一种轻量级 Transformer 框架，将组织架构重新表述为对离散细胞 token 的掩码上下文预测任务。通过在没有任务特定监督的情况下学习上下文化的 [CLS] 嵌入，该模型能够捕获高阶细胞交互，同时保持计算高效。我们在多个临床相关下游任务上评估 MUL-T，包括组织芯级肿瘤模式分类、患者级分级、PD-L1 阳性预测和跨数据集治疗反应预测。在各项任务中，MUL-T 始终优于基于经典特征的基线方法，并取得与基础 ViT 模型相当的性能，尽管参数数量大幅减少且训练成本更低。

## Abstract
Understanding tissue organisation in multiplexed imaging requires modelling both cellular phenotypes and their spatial context. Existing approaches typically rely on handcrafted features, such as marker intensity statistics or cell-type proportions, which often fail to scale or generalise across cohorts with heterogeneous marker panels. We introduce MUL-T, a lightweight transformer framework that reframes tissue architecture as a masked contextual prediction task over discrete cell tokens. By learning contextualised [CLS] embeddings without task-specific supervision, the model captures higher-order cellular interactions while remaining computationally efficient. We evaluate MUL-T on several clinically relevant downstream tasks, including core-level tumour pattern classification, patient-level grading, PD-L1 positivity prediction, and cross-dataset treatment response prediction. Across tasks, MUL-T consistently outperforms classical feature-based baselines and achieves performance comparable to a foundation ViT model, despite substantially fewer parameters and lower training cost.

## 1. 论文的核心问题与整体含义

- **研究背景**：多重免疫荧光（mIF）与空间蛋白质组技术能够提供单细胞分辨率的高维空间数据，但组织结构的复杂性远超传统分析方法的处理能力。
- **核心问题**：现有方法存在以下主要不足：
  - 基于手工特征（如标志物强度统计、细胞类型比例）的方法难以跨异质标志物面板和大队列泛化。
  - 基于图神经网络的方法假设局部同质性，容易稀释稀有细胞信号，且计算成本高。
  - 基于 Vision Transformer（ViT）的瓦片级方法将多通道荧光信号压缩为 RGB 或固定网格，混淆了标志物语义与空间结构，难以跨队列迁移，且会模糊细胞边界。
- **整体含义**：作者将组织架构重新表述为一种“细胞语言”——单个细胞视为离散 token，空间局部区域视为序列，利用掩码上下文预测任务学习组织架构的表示，从而在无需任务特定监督的情况下捕获高阶细胞交互。

## 2. 论文提出的方法论

- **核心思想**：通过类比自然语言处理，将组织图像中的细胞及其空间排列建模为 token 序列，使用轻量级 Transformer 学习上下文化的 [CLS] 嵌入，用于下游任务。
- **关键技术流程**：
  1. **细胞分割**：使用 U-Net 框架，基于 DAPI 通道识别细胞核，再扩展至全细胞，提取每个细胞的坐标与多标志物强度。
  2. **表型聚类（Tokenisation）**：从约 1700 万细胞中抽样 500 万，使用 K-means（K=10）对标准化标志物强度、细胞面积和圆度特征进行聚类，得到 10 个表型 cluster token。
  3. **网格离散化**：计算每个细胞到第 2 近邻的距离中位数 \(d\)，以 \(\Delta = \alpha d\)（\(\alpha=2\)）为网格尺寸，将细胞分配到最近网格 bin。有细胞的 bin 继承其 cluster 编号，无细胞的 bin 编码为背景 token。
  4. **窗口构建**：每个输入序列由 30×30 的 token 网格展平得到，长度为 900；加入旋转位置编码（RoPE）。
  5. **掩码预训练**：采用微型 BERT 风格 Transformer 编码器（4 层、4 头、嵌入维度 256，共约 3.5M 参数）；词汇表共 13 个 token（10 个表型 cluster、1 个背景、1 个 [CLS]、1 个掩码）。随机掩蔽 20–30% 的 token（背景 token 不参与掩蔽），使用交叉熵损失仅在被掩蔽位置计算：
     \[
     L_{\text{MLM}} = -\frac{1}{|M|} \sum_{i\in M} w_{y_i} \log p_\theta(y_i|x)
     \]
     其中 \(w_{y_i}\) 为可选的类别权重。
  6. **嵌入聚合**：每个窗口的 [CLS] 嵌入通过平均池化聚合为组织芯级表示，再对多芯患者取平均得到患者级表示。
  7. **下游分类**：使用逻辑回归（多分类采用一对多策略）对聚合后的表示进行预测。

- **跨数据集 token 转移**：在共享标志物（CD4、CD8、CD68、Ki67、Cytokeratin、核标志物）上，使用 k-NN（k=250）分类器将主数据集的 cluster token 投票转移到外部数据集；每个目标细胞的置信度由投票比例定义。

## 6. 论文的主要结论与发现

- MUL-T 在四个下游任务上取得了以下 AUC：肿瘤模式分类 0.86、患者分级 0.79、PD-L1 阳性 0.72、跨数据集治疗反应预测 0.68。
- 在所有任务中，MUL-T 均优于两种经典特征基线，与基础 ViT 模型 KRONOS 的性能相当，但参数量仅 3.5M，训练成本大幅降低。
- 掩码 token 预测能够学到组织架构中的高阶空间规律；[CLS] 嵌入在 UMAP 中按主要肿瘤模式形成清晰分离。
- 跨数据集 token 转移在共享标志物上具有较高的生物学一致性（标志物平均 Pearson 相关系数为 0.8545），表明该方法支持面板异质队列之间的知识迁移。
- 可扩展性分析显示，模型在极小数据比例（1%）时已快速捕获主要统计结构，之后性能趋于饱和，提示性能瓶颈更多在于模型容量而非数据量。

## 7. 优点

- **轻量高效**：3.5M 参数的微型 Transformer 即可达到与大型基础 ViT 相当的性能，训练和部署成本低，适合临床资源受限环境。
- **细胞级建模**：直接以细胞为 token，避免了瓦片级方法对细胞边界的模糊和稀有信号的稀释，保留生物学分辨率。
- **自监督学习**：掩码上下文预测无需任务特定标签，学习到的表示具有跨任务和跨数据集的迁移潜力。
- **网格 token 化设计**：基于经验细胞间距自适应确定网格大小，使用背景 token 保留空间间隔，避免了人工邻接和距离塌缩。
- **可解释性好**：下游仅使用逻辑回归和平均聚合，表示质量直接决定预测性能，便于临床解读和验证。
- **跨数据集策略**：基于共享标志物的 k-NN 投票实现 token 迁移，为面板异质队列的泛化提供可行方案。

## 8. 不足与局限

- **网格离散化损失**：将细胞分配到规则网格可能平滑精细空间变异，尤其在细胞高度密集或稀有表型区域；极端组织结构下假设可能不成立。
- **局部窗口限制**：仅使用 30×30 窗口，不显式建模长程组织级空间依赖；某些全局组织结构（如肿瘤边界、侵袭前沿）可能未被充分捕获。
- **上游依赖**：性能受细胞分割和表型聚类质量影响；分割或聚类错误会传播到下游表示。
- **跨数据集等价性**：共享标志物的生物学对应并非完全等价，染色协议和面板差异仍可能导致域偏移；仅在一个外部数据集验证，泛化证据有限。
- **下游模型上限**：使用平均池化和线性分类器可能限制在复杂任务上的性能天花板，与端到端微调相比可能不足。
- **消融有限**：关键超参数（窗口尺寸、α、K、掩蔽比例）未系统消融，模型设计选择缺乏敏感性分析。
- **统计报告不足**：未提供置信区间或标准误差，类别不平衡的具体处理细节也不充分，可能影响结果稳健性判断。
