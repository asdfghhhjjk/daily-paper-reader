## 摘要
识别和表示诸如细胞或细胞核等对象实例是显微图像分析中的常见任务。现有的机器学习工作流程通常使用有监督的检测或分割，然后进行特征提取或分类，这需要人工标注，并将实例分割和细胞表示视为分开的阶段。我们描述了一种新的无监督方法，用于从未标记的显微图像中进行细胞实例分割和表型分类。我们的方法基于使用从粗到细的路由金字塔重建每幅图像，该金字塔将像素与空间稀疏的潜在源相关联。由此产生的像素到潜在的关联产生实例掩码，而源潜在变量编码细胞形态。我们证明了在多种细胞形态和成像模态下实例分割的竞争性能，以及在扰动下细胞表型的生成建模。源代码和检查点可在 https://github.com/weigertlab/routing-pyramids 获取。

## Abstract
Identifying and representing object instances such as cells or nuclei is a common task in microscopy image analysis. Established machine learning workflows typically use supervised detection or segmentation followed by feature extraction or classification, which requires manual annotations and treats instance segmentation and cell representation as separate stages. We describe a new unsupervised method for cell instance segmentation and phenotypic classification from unlabeled microscopy images. Our method is based on reconstructing each image using a coarse-to-fine routing pyramid that associates pixels with spatially sparse latent sources. The resulting pixel-to-latent associations yield instance masks, while the source latents encode cell morphology. We demonstrate competitive performance in instance segmentation across diverse cell morphologies and imaging modalities, as well as generative modeling of cellular phenotypes under perturbations. Source code and checkpoints are available at https://github.com/weigertlab/routing-pyramids.

## 2. 论文提出的方法论

### 2.1 核心思想

- 模型基于**图像重建**：用一组空间稀疏的潜在源（latent sources）解释整幅图像。
- 通过**从粗到细的路由金字塔（routing pyramid）**，把每个像素逐步关联到某个潜在源。
- 像素到潜在源的关联既用于重建图像，也直接产生实例掩码；潜在源本身编码细胞形态。

### 2.2 关键技术细节

- **编码器与潜在场**：
  - 输入图像 \(x\)，编码器 \(E_\phi\) 输出特征 \(f\)，分辨率为输入下采样 \(\delta=8\) 的网格 \(\Omega_0\)。
  - 针对前景和背景分别预测对角高斯后验 \(q_\phi(z^{fg}|x)\) 和 \(q_\phi(z^{bg}|x)\)，潜在维度 \(d=64\)。
  - 背景潜在经过平均池化（stride \(\delta_{bg}=8\)）再恢复，使其在空间上平滑。

- **软存在门（presence gate）**：
  - 对每个前景候选位置 \(u\)，用 sigmoid 得到软存在值 \(s_u\)。
  - 解码器初始特征 \(h^0_u = s_u z^{fg}_u + (1-s_u) z^{bg}_u\)。
  - 前景存在被稀疏性正则化惩罚，因此模型只有在真正需要前景容量时才会激活某个种子。

- **路由金字塔解码器**：
  - 解码器包含多个层，每层目标网格 \(\Omega_\ell\) 中的每个位置 \(j\) 在其上一层（父层）的局部 \(3\times 3\) 邻域 \(N_\ell(j)\) 中选择父位置。
  - 通过 softmax 得到局部条件概率 \(T^\ell_{ji}\)，表示目标位置 \(j\) 选择父位置 \(i\) 作为来源的概率。
  - 这些局部路由形成一个有向无环图（DAG），从输出像素指向潜在种子网格。
  - 将各层转移核组合，得到像素到种子的关联矩阵 \(A_{nu}\)：
    \[
    A_{nu} = \sum_{\gamma \in \Gamma(n,u)} \prod_\ell T^\ell_{\gamma_\ell \gamma_{\ell-1}}
    \]
    表示输出像素 \(n\) 的分配质量到达种子 \(u\) 的概率。
  - 传播后的前景概率 \(p^{fg}_n = \sum_{u} A_{nu} s_u\)。

- **生成过程与路由共享**：
  - 在生成方向，同一组路由权重将父层表示和存在值聚合到目标位置：
    \[
    s^\ell_j = \sum_i T^\ell_{ji} s^{\ell-1}_i,\quad r^\ell_j = \sum_i T^\ell_{ji} V_\ell(h^{\ell-1}_i)
    \]
  - 经过归一化、激活、乘以前景存在值、残差连接和前馈块后，逐层上采样，最终映射为重建图像 \(\hat{x}\)。

- **训练目标**：
  - 重建损失：\(L_{rec} = \mathbb{E}_{q_\phi(z|x)} \left[ \frac{1}{HWC} \|\hat{x}_\theta(z) - x\|_1 \right]\)
  - 前景/背景 KL 正则项：\(L^{fg}_{KL}, L^{bg}_{KL}\)，使后验接近标准正态先验。
  - 稀疏性惩罚：
    \[
    L_{sparsity} = \frac{1}{|\Omega_0|} \sum_u \left( (s_u + \epsilon)^\alpha - \epsilon^\alpha \right), \quad \alpha=0.5
    \]
    鼓励前景容量集中到更少的种子区域。
  - 流动正则项 \(L_{flow}\)：对局部路由期望的几何步长平方进行惩罚，避免异常大的空间跳跃。
  - 总损失：
    \[
    L = \lambda_{rec}L_{rec} + \lambda_{fg}L^{fg}_{KL} + \lambda_{bg}L^{bg}_{KL} + \lambda_{flow}L_{flow} + \lambda_{sparsity}L_{sparsity}
    \]
    权重：\(\lambda_{rec}=1.0, \lambda_{fg}=0.01, \lambda_{bg}=0.05, \lambda_{flow}=0.005\)，\(\lambda_{sparsity}=0.2\) 或 \(0.5\)；前 10 个 epoch 对正则项做线性 warmup。

- **实例分割与对象表示**：
  - 推理时使用后验均值替代采样。
  - 对 \(s_u \ge \tau_s=0.5\) 的种子做 8 连通域标记，每个连通域 \(C_k\) 作为对象种子。
  - 对每个像素计算各对象的质量 \(m_k(n) = \sum_{u\in C_k} A_{nu} s_u\)。
  - 若最大质量 \(\ge \tau_m=0.1\)，将像素分配给该对象，否则为背景。
  - 过滤最小面积（模型分辨率网格上 100 像素），再上/下采样到原图分辨率。
  - 对象级表示 \(e_k\) 为前景后验均值的存在加权平均：
    \[
    e_k = \frac{\sum_{u\in C_k} s_u \mu^{fg}_u}{\sum_{u\in C_k} s_u}
    \]

## 6. 论文的主要结论与发现

- 在无监督设定下，Generative Routing Pyramids 在三个数据集上几乎在所有指标上优于无监督基线 Cellulus 和非参数 Otsu。

- 在 BBBC013 药物扰动实验中：
  - 学习到的对象潜在编码在 UMAP/PCA 空间中按剂量形成明显聚类。

- 总体结论：无监督生成式路由金字塔能够在一个模型中同时完成细胞实例分割和形态表示学习，并在多种成像条件下取得竞争性结果。

## 7. 优点

- **统一框架**：不需要分别训练分割模型和特征提取模型，直接从图像重建中学到实例和表示。
- **端到端无监督训练**：无需任何实例掩码、中心点或流动目标。
- **计算效率较好**：推理复杂度 \(O(N)\) 用于候选源预测和特征传播，避免全局 slot 或迭代推断的高成本；与 SPACE、Slot Attention 等方法相比更具可扩展性。
- **可解释的物理意义**：像素到种子的路由关联可以直接解释为实例分配，也可读出类似 Cellpose 的中心流。
- **后处理参数统一**：在三个数据集上使用相同阈值，不像 Cellulus 和 Otsu 需要 dataset-specific 后处理。
- **生成能力**：不仅能分割和表示，还能从潜在分布采样生成新细胞图像，适用于表型建模。
- **在 Allen 数据集上展现出严格的边界准确性**，在 IoU 0.9 下明显超过监督参考。
