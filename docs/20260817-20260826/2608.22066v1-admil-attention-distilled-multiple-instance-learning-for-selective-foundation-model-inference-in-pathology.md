## 摘要
基于病理学基础模型嵌入的注意力多实例学习（ABMIL）对切片级任务有效，但穷举推理需要将大型图像编码器应用于每个前景瓦片，尽管后续注意力分布通常集中在少量信息区域上。我们提出了 ADMIL（注意力蒸馏多实例学习），一个选择性计算框架，将 ABMIL 教师模型的注意力蒸馏到一个轻量级瓦片选择模型 PriorNet 中。PriorNet 采用 EfficientNet 架构，通过 KL 散度从原始瓦片像素中学习教师注意力分布；推理时，它对前景瓦片池打分，选择 top-K 个瓦片，并仅在该子集上调用昂贵的基础模型，随后由基于所选包训练的 ABMIL 学生模型预测切片标签。在 BRACS、PANDA 和 CAMELYON16 数据集上，ADMIL 分别在 K=4、8 和 128 个瓦片时达到与完整教师模型相当的主要性能，同时避免了超过 98% 的基础模型（Virchow2）瓦片嵌入和模型推理 FLOPs。随机选择和教师注意力 oracle 对照实验表明，这一结果依赖于任务相关的选择，而不仅仅是瓦片数量的减少。定量和定性分析表明，PriorNet 能以高保真度恢复教师模型的瓦片排序，同时聚焦于任务相关的形态学区域。ADMIL 表明，几乎可以去除所有昂贵的瓦片编码而不牺牲切片级性能，为在延迟和计算成本是关键考虑因素的临床环境中更高效部署提供了一条潜在路径。

## Abstract
Attention-based multiple instance learning (ABMIL) using pathology foundation model embeddings is effective for slide-level tasks, but exhaustive inference requires applying a large image encoder to every foreground tile despite the subsequent attention distribution often concentrating over a small subset of informative regions. We introduce ADMIL (Attention-Distilled Multiple Instance Learning), a selective-compute framework that distills an ABMIL teacher's attention into a lightweight tile-selection model, PriorNet. Using an EfficientNet architecture, PriorNet learns the teacher attention distribution from raw tile pixels with KL divergence; at inference, it scores the foreground pool, selects the top-K tiles, and invokes the expensive foundation model only on that subset before a selected-bag ABMIL student predicts the slide label. Across BRACS, PANDA, and CAMELYON16, ADMIL matches full-teacher headline performance at K=4, 8, and 128 tiles, respectively, avoiding >98% of foundation model (Virchow2) tile embeddings and model inference FLOPs. Random and teacher-attention oracle controls show that this result depends on task-relevant selection rather than tile-count reduction alone. Quantitative and qualitative analyses suggest that PriorNet recovers the teacher's tile ordering with high fidelity while focusing on task-relevant morphological regions. ADMIL shows that nearly all expensive tile encodings can be removed without sacrificing slide-level performance, providing a potential path for more efficient deployment in clinical settings where latency and compute costs are key considerations.

## 1. 论文的核心问题与整体含义

- **研究背景**：病理全切片图像（WSI）分析通常采用“前景瓦片提取 → 病理基础模型逐瓦片编码 → 注意力多实例学习（ABMIL）聚合”的流程。该方法在转移检测、肿瘤分型、组织学分级等任务上性能优秀，但计算开销巨大：一张 WSI 可能包含数千到数万个前景瓦片，需要全部通过大型基础模型（如 Virchow2）编码。
- **核心矛盾**：训练后的 ABMIL 模型虽然对所有瓦片进行了编码，但其注意力分布往往高度集中在少数形态学信息区域。也就是说，大量昂贵的基础模型推理被浪费在对最终预测贡献很小的瓦片上。
- **整体含义**：论文提出 ADMIL 框架，将教师 ABMIL 的注意力分布蒸馏到一个轻量级瓦片选择模型 PriorNet 中，在推理阶段先用 PriorNet 筛选出最有价值的 top-K 个瓦片，再仅对这些瓦片调用昂贵的基础模型。这能够在几乎不损失切片级性能的前提下，避免超过 98% 的基础模型瓦片嵌入和推理 FLOPs，为临床环境中的低延迟、低成本部署提供可行路径。

## 2. 论文提出的方法论

- **核心思想**：不替换或压缩基础模型本身，而是学习一个任务相关的“门控”策略，在调用昂贵编码器之前预先筛选高价值瓦片。
- **整体流程**：
  1. **训练全量教师模型**：使用 Virchow2 基础模型对每个前景瓦片编码，训练标准 ABMIL 教师模型，得到全量瓦片上的注意力分布 \(\alpha\)。
  2. **Stage 1 —— 注意力蒸馏**：训练轻量级 PriorNet（EfficientNet-B0），输入原始瓦片像素 \(x_i\)，输出标量分数 \(s_i\)，经 softmax 归一化得到预测注意力分布 \(q\)。使用 KL 散度损失 \(L_{\text{prior}} = D_{\text{KL}}(\alpha \| q)\) 训练 PriorNet，使其逼近教师注意力分布。
  3. **Stage 2 —— Top-K 选择与 Selected-Bag ABMIL 训练**：推理时 PriorNet 对全部前景瓦片打分，选择分数最高的 K 个瓦片。仅对这些瓦片调用 Virchow2 编码，得到嵌入 \(z_i\)；再训练一个独立的“selected-bag”ABMIL 学生模型，只在所选 K 个瓦片上计算注意力并预测切片标签。
- **关键技术细节**：
  - **注意力引导采样**：为降低训练成本并强化高注意力瓦片的学习，PriorNet 训练时每个 WSI 只使用 \(Z\%\) 的前景瓦片（主实验 \(Z=10\%\)），其中一半来自教师注意力 top 的瓦片，另一半从剩余池中随机采样；KL 散度在采样后的子集上重新归一化。
  - **可调部署预算 K**：不同任务可选择不同的 K。学生 ABMIL 针对每个 K 单独训练；PriorNet 与 K 无关，训练一次即可用于任意预算。
  - **公式要点**：教师注意力 \(a_i = w_a^\top \tanh(W_a z_i + b_a)\)，\(\alpha_i = \text{softmax}(a_i)\)；PriorNet 得分 \(s_i = p_\phi(x_i)\)，\(q_i = \text{softmax}(s_i)\)；学生注意力 \(\rho_i = w_b^\top \tanh(W_b z_i + b_b)\)，仅对 \(i \in S_K(X)\) 计算。

## 3. 实验设计

- **数据集与任务**：
  - **CAMELYON16**：乳腺癌淋巴结转移检测（二分类），平均每张 WSI 约 12,391 个前景瓦片，使用官方 270 张开发集 / 129 张测试集。
  - **PANDA**：前列腺活检 ISUP 分级（六分类），平均每张约 531 个前景瓦片；因无官方测试划分，按 90/10% 划分开发/测试，并按患者级别划分以防止数据泄漏。
  - **BRACS**：乳腺活检三分类（良性 / 非典型 / 恶性），平均每张约 2,513 个前景瓦片，使用官方划分。
- **基础模型与聚合器**：基础模型固定为 Virchow2；教师和学生的聚合器均为非门控 ABMIL，包含 512 维 tanh 注意力层、标量注意力打分器及 512 维隐藏层的任务头。
- **对比方法**：
  - **全量基础模型 ABMIL 教师**：对每个前景瓦片编码，作为全计算性能参考。
  - **随机 top-K**：随机均匀采样 K 个瓦片，训练独立 ABMIL，用于控制“任意子集是否足够”。
  - **教师 top-K oracle**：使用教师全量注意力选择 top-K，不可实际部署（因为获取教师注意力需要全量编码），但用于估计完美恢复教师证据时的性能上限。
  - **ADMIL**：本文提出的 PriorNet 选择 + selected-bag ABMIL。
- **评价指标**：CAMELYON16 用 AUROC 和 AUPRC；PANDA 用 quadratic weighted kappa (QWK) 和 within-1 accuracy；BRACS 用 balanced accuracy 和 macro one-vs-rest AUROC。所有结果基于三个随机种子（0/1/2）的平均，并用 1,000 次层次 bootstrap 估计 95% 置信区间。
- **额外分析**：注意力保真度（Pearson / Spearman 相关、教师支持检索矩阵）、注意力图定性分析、PriorNet 监督采样比例 \(Z \in \{5\%, 10\%, 20\%\}\) 的敏感性分析。

## 6. 论文的主要结论与发现

- **性能匹配**：ADMIL 在极小瓦片预算下即可达到全量教师模型的主要性能：
  - BRACS：K=4 时 balanced accuracy 达到 0.670（教师 0.648，95% CI 重叠）；
  - PANDA：K=8 时 QWK 达到 0.858（教师 0.854）；
  - CAMELYON16：K=128 时 AUROC 达到 0.978（教师 0.976）。
- **计算节省**：对应避免 99.8%、98.5%、99.0% 的基础模型瓦片嵌入；模型推理 FLOPs 节省 99.6%、98.3%、98.7%。
- **选择机制有效性**：ADMIL 显著优于随机 top-K（尤其在低 K 区域），并接近 teacher top-K oracle，说明性能优势来自任务相关的注意力蒸馏选择，而非单纯的瓦片数量减少。
- **注意力保真度**：PriorNet 与教师注意力的 Spearman 相关较高（CAMELYON16 0.799，PANDA 0.839，BRACS 0.579），且 Spearman 高于 Pearson，说明 PriorNet 更擅长恢复排序而非精确概率值。
- **定性可解释性**：注意力图显示学生模型聚焦于与标签一致的形态学区域（如 CAMELYON16 中的肿瘤细胞、PANDA 中的高级别前列腺癌）。
- **鲁棒性**：对 PriorNet 监督采样比例 \(Z\)（5%、10%、20%）不敏感，性能曲线和置信区间基本重叠。

## 7. 优点

- **任务针对性选择**：不同于任务无关的瓦片筛选或模型压缩，ADMIL 蒸馏教师 ABMIL 的任务特定注意力，选择与当前分类任务最相关的瓦片。
- **保留高容量表示**：不替换基础模型，只在选中的瓦片上调用原始 Virchow2 编码器，避免了因特征蒸馏或降级带来的潜在性能损失。
- **轻量级开销**：PriorNet 推理成本极低（约 0.769 GFLOPs/瓦片），即使扫描全部前景瓦片，其开销也仅占全教师模型前向 FLOPs 的约 0.226%。
- **可解释性分析充分**：通过相关性、检索矩阵和注意力图多角度验证了 PriorNet 确实学到了教师注意力排序，而非偶然有效。
- **方法简单可扩展**：两阶段训练流程清晰，PriorNet 与 K 无关，可适配不同部署预算；selected-bag ABMIL 沿用标准 ABMIL 结构，易于复现。
- **对照实验严谨**：随机与 oracle 对照有效排除了“任意子集足够”的替代解释。

## 8. 不足与局限

- **依赖教师注意力质量**：若教师 ABMIL 注意力分散、不稳定或关注混杂因素，蒸馏得到的 PriorNet 可能继承这些缺陷，导致选择不可靠。论文未系统评估教师注意力质量对 ADMIL 的影响。
- **Kcrit 的事后性**：用于报告计算节省的临界预算 Kcrit 是基于测试集性能曲线事后选取的，并非由验证集确定的部署超参数；实际部署时需在验证集上选择 K，论文未提供相应流程和结果。
- **实验覆盖有限**：
  - 仅使用一个基础模型（Virchow2），未验证对其他病理基础模型（如 UNI、CONCH、Prov-GigaPath）的适用性。
  - 仅三个公开数据集，且 PANDA 为自建划分，缺少更多样化的病理任务（如生存预测、多标签分类）和多中心数据。
- **未报告实际系统效率**：FLOPs 节省不等同于实际延迟或吞吐量提升；论文未测量端到端推理时间、内存占用或 I/O 开销，也未考虑瓦片提取和预处理成本。
- **训练阶段额外开销**：ADMIL 需要先训练教师模型，再训练 PriorNet 和多个 selected-bag 学生模型，训练成本高于直接训练全量 ABMIL；论文未讨论该训练开销的规模或优化空间。
- **BRACS 相关性偏低**：BRACS 上 Spearman 相关仅 0.579，但仍能在 K=4 时匹配教师性能，说明性能匹配可能部分源于任务本身对少量高置信瓦片的依赖性，而非 PriorNet 的高保真恢复；这一现象未深入解释。
- **缺少组件消融**：未单独分析注意力引导采样策略、PriorNet 架构选择、KL 蒸馏损失中平滑项 \(\epsilon\) 等设计的影响。
