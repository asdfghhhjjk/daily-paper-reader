## 摘要
弱监督全切片图像（WSI）分类在计算病理学中被广泛采用，因为切片级标签比密集区域注释更易获取。现有的多实例学习（MIL）方法通常主要依赖视觉线索聚合大量补丁嵌入，这可能保留许多非信息性补丁，并导致实例特征与类别级疾病语义之间的对齐较弱。我们提出概念引导的剪枝与表征学习（CGRL），这是一个简单的框架，将疾病提示衍生的类别级概念原型引入MIL流程。首先，概念相关性剪枝根据补丁与类别概念的相似度进行排序，保留前K个最相关的补丁用于下游MIL聚合。其次，概念引导的对比表征学习从同一相似度矩阵构建类别正负补丁集，并优化目标类、对称辅助和跨类分离目标，从而正则化投影的概念空间。我们在TCGA-BRCA和TCGA-NSCLC上使用多种代表性MIL方法评估CGRL。实验结果表明，CGRL在多个模型-数据集组合上有所改进，效果取决于下游MIL模型和数据集。它在准确率和宏F1方面取得了特别明显的提升，同时通过概念相关性剪枝降低了计算成本。这些发现表明，类别级语义概念为弱监督计算病理学中的补丁选择和表征学习提供了有效且实用的先验。

## Abstract
Weakly supervised whole-slide image (WSI) classification is widely used in computational pathology because slide-level labels are easier to obtain than dense region annotations. Existing multiple instance learning (MIL) methods often aggregate large bags of patch embeddings using mainly visual cues, which can retain many non-informative patches and provide weak alignment between instance features and class-level disease semantics. We propose Concept-Guided Pruning and Representation Learning (CGRL), a simple framework that introduces class-level concept prototypes derived from disease prompts into the MIL pipeline. First, concept-relevance pruning ranks patch instances by their similarity to class concepts and retains the top-K concept-relevant patches for downstream MIL aggregation. Second, concept-guided contrastive representation learning constructs class-wise positive and negative patch sets from the same similarity matrix and optimizes target-class, symmetric auxiliary, and cross-class separation objectives, thereby regularizing the projected concept space. We evaluate CGRL on TCGA-BRCA and TCGA-NSCLC using multiple representative MIL methods. Experimental results show that CGRL improves several model-dataset combinations, with gains depending on the downstream MIL model and dataset. It achieves particularly clear improvements in accuracy and macro-F1 while reducing computational cost through concept-relevance pruning. These findings demonstrate that class-level semantic concepts provide an effective and practical prior for patch selection and representation learning in weakly supervised computational pathology.

### 2. 方法论（核心思想与关键技术细节）
CGRL 是一个即插即用的框架，其核心思想是利用冻结的视觉-语言模型将图像块与类别概念映射至共享语义空间，并在此空间中完成两项互补操作：

- **概念相关性剪枝（Concept-Relevance Pruning）**
  - 使用预训练文本编码器（TITAN）将疾病提示文本编码为 `C` 个类别概念原型 `T = {t_c}`。
  - 通过一个可学习的轻量投影头 `g` 将原始图像块嵌入 `x_i` 映射到概念空间，得到 `u_i`。
  - 计算每个图像块 `i` 与所有概念原型的余弦相似度 `S_{i,c}`，将块的概念相关性得分定义为 `r_i = max_c S_{i,c}`。
  - 保留 `r_i` 最高的 `K_p`（实验中取300）个图像块，将其原始嵌入（非投影后的）送入下游MIL模型进行幻灯片级预测，从而大幅缩减实例数。

- **概念引导的表征学习（Concept-Guided Representation Learning）**
  - 利用同一相似度矩阵 `S`，针对每一类别 `c` 构造正样本集（与概念原型最相似的 `K_pos` 个投影特征）和负样本集（最不相似的 `K_neg` 个）。
  - 设计三个对比损失（基于InfoNCE），仅作用于投影特征 `u_i`，在训练阶段辅助规约概念空间：
    - **目标类损失** `L_y`：拉近真实类别 `y` 的正样本与其概念原型，同时推远其负样本。
    - **对称辅助损失** `L_sym`：对所有非目标类 `c ≠ y` 执行同样的正-原型对齐与正负分离，强化各类别语义的独立结构。
    - **跨类分离损失** `L_cross`：让目标类正样本靠近非目标类的负样本均值原型 `p_{y→c}`，并远离非目标类的正样本，进一步拉开类间边界。
  - 总概念表征损失 `L_CGRL = L_y + λ_sym L_sym + λ_cross L_cross`。
  - 最终训练损失为 MIL 分类损失 `L_cls` 与 `L_CGRL` 的加权和。

- **推理阶段**：仅保留概念相关性剪枝，移除所有对比学习部分，因此不增加推理时的计算开销。

  - TCGA-NSCLC：958张WSI，分类为肺腺癌（LUAD）与肺鳞状细胞癌（LUSC）。

  - CLAM-SB

### 6. 论文的主要结论与发现
- CGRL作为一个轻量的即插即用模块，能有效将类别语义概念注入弱监督WSI分类流程。
- 在多个模型-数据集组合中，CGRL相比全量块和普通采样基线显著提升了**准确率（ACC）和宏F1**等阈值相关指标，表明其选择的块更具类别可分辨性。
- 同时，通过剪枝 `K_p=300` 个块，大幅减少了 MIL 聚合器的输入实例数，从而降低了计算成本（如FLOPs的减少）。

- 整体结论：利用文本医学概念作为先验，在补丁选择和表征正则化两个层面都具有实用价值。

### 7. 优点
- **思想直观且即插即用**：无需改变下游MIL模型结构，只需在输入端增加剪枝和训练时增加辅助损失，易于与现有方法集成。
- **双重利用语义概念**：概念原型既作为补丁的选择器（解决冗余），又作为对比学习的监督信号（改善特征空间），设计连贯。
- **显著提升核心指标**：在多个配置下显著提高ACC和F1，而这些指标恰是病理决策中更关注的分类能力衡量。

- **实验对比充分**：将CGRL与随机和聚类采样对比，有力证明了“概念引导”带来的额外增益。
