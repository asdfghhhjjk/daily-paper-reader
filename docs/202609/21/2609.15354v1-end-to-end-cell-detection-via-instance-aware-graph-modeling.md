## 摘要
准确的细胞检测与分类对病理分析至关重要，直接影响诊断准确性和治疗规划。为了捕捉肿瘤微环境中超越视觉外观的复杂细胞交互，已有多种方法采用图神经网络对细胞核之间的空间与关系模式进行建模，取得了有前景的结果。然而，这些方法通常采用先视觉提取后关系建模的两阶段范式，每个阶段需要单独调参，从而增加了流程复杂度，并阻碍了端到端联合优化。本文提出一种端到端的细胞检测与分类框架，联合建模图像块级视觉表示与实例级交互，其中包含动态图构建模块和实例感知图网络。具体而言，图构建模块利用从图像块级特征中得到的可学习查询作为细胞实例表示来动态构建图结构，并通过融合特征相似性与空间距离来定义邻接关系。实例感知图网络执行自适应实例过滤与特征重组，将其在细胞图上聚合为拓扑潜在状态，用于由视觉线索驱动的选择性状态空间转移，从而融合外观与关系证据。在多个采用不同染色方案的细胞与细胞核检测数据集上进行评估时，我们的方法在检测和分类性能上均显著优于现有方法。代码将发布于 https://github.com/RuochenLiu23/IGM。

## Abstract
Accurate cell detection and classification are crucial for pathological analysis, directly affecting diagnostic accuracy and treatment planning. To capture complex cellular interactions beyond visual appearance within the tumor microenvironment, several approaches have employed graph neural networks to model spatial and relational patterns among cell nuclei, yielding promising results. However, these methods typically adopt a two-stage paradigm of visual extraction followed by relational modeling, which necessitates separate tuning for each stage, thereby increasing pipeline complexity and hindering end-to-end joint optimization. In this paper, we propose an end-to-end framework for cell detection and classification that jointly models patch-level visual representations and instance-level interactions, which incorporates a dynamic graph construction module and an instance-aware graph network. Specifically, the graph construction module dynamically builds the graph structure using learnable queries derived from patch-level features as cell instance representations, with adjacency defined by integrating feature similarity and spatial distances. The instance-aware graph network performs adaptive instance filtering and feature reorganization, aggregating them over the cell graph into a topological latent state for a selective state-space transition driven by visual cues, fusing appearance and relational evidence. When evaluated on multiple datasets with different staining protocols for cell and nucleus detection, our method significantly outperforms existing approaches in both detection and classification performance. The code will be released at https://github.com/RuochenLiu23/IGM.

## 2. 论文提出的方法论

### 2.1 整体框架组成

论文提出的框架包含三个核心组件：

1. **查询特征学习网络（Query Feature Learning Network）**：从病理图像块中提取多尺度视觉特征，生成高质量查询嵌入，实现图像块级特征到实例级表示的映射。
2. **动态图构建模块（Dynamic Graph Construction, DGC）**：以查询为节点，融合空间距离和特征相似度动态构建细胞图。
3. **实例感知图网络（Instance-aware Graph Network, IGN）**：对查询图进行关系建模，输出融合外观与拓扑关系的特征，用于分类和边界框回归。

### 2.2 查询特征学习网络

- 输入病理图像经过骨干网络（默认 ResNet-50）得到多尺度特征。
- 多尺度特征展平、拼接并加入 2D 正弦位置编码，经 Transformer 编码器（多尺度可变形注意力）增强，得到增强视觉特征。
- 从增强特征中生成候选框（锚点），经类别无关 NMS 筛选 top-N 高质量候选，提取对应位置特征，与可学习查询向量相加得到最终查询嵌入。
- 查询嵌入与 4D 参考点（中心坐标、宽高）输入 Transformer 解码器，通过自注意力和多尺度可变形交叉注意力迭代更新查询。
- 解码器输出的查询特征 \(Q\) 和更新后的参考点 \(P\) 作为后续图构建的输入。

### 2.3 动态图构建（DGC）

- 对任意两个查询 \(i,j\)，定义空间距离 \(s^p_{ij}\) 为参考点欧氏距离的指数衰减；特征距离 \(s^f_{ij}\) 为查询特征 L2 归一化后的余弦相似度。
- 综合距离：  
  \[
  s_{ij} = \alpha \cdot (1 - s^p_{ij}) + (1-\alpha) \cdot (1 - s^f_{ij})
  \]
  其中 \(\alpha\) 为权重，实验确定 \(\alpha=0.5\) 时最优。
- 基于综合距离使用 KNN 建立节点连接，得到邻接矩阵 \(M\)，构成查询图 \(G=(V,E)\)。图结构随查询特征和参考点的更新而动态变化，通过梯度传播实现端到端优化。

### 2.4 实例感知图网络（IGN）

IGN 由**实例感知图学习（IGL）** 和**拓扑结构状态空间（Topology-structured State Space, TSS）** 两个耦合模块组成，并使用**上下文引导状态编码（CGSE）** 生成状态转移参数。

#### 2.4.1 实例感知图学习（IGL）

- **选择性特征重组（Selective Feature Reorganization, SFR）**：
  - 对节点特征 \(x_i\)，通过动态生成的逐元素门控矩阵 \(\Delta_i\) 和方向矩阵 \(B_i\)，将节点特征映射到隐藏状态 \(h_i = (\Delta_i \odot x_i) \otimes B_i\)。
  - \(\Delta_i\) 控制信息写入量，实现自适应过滤；\(B_i\) 将特征扩展到方向性潜在空间，使相似节点方向接近、不相似节点接近正交。
- **方向性图聚合（Directional Graph Aggregation）**：
  - 将所有节点状态 \(h\) 在细胞图上进行对称归一化邻接聚合：
    \[
    \hat{h} = D^{-1/2}(M+I)D^{-1/2} h
    \]
  - 因为节点状态沿各自方向分布，聚合相当于在近正交方向上的重叠，语义不一致邻居不会污染目标节点自身状态，从而实现无需显式剪枝的抗噪图聚合。

#### 2.4.2 拓扑结构状态空间（TSS）

- 将图聚合得到的拓扑表示 \(\hat{h}\) 作为潜在状态，以查询的视觉特征 \(x\) 驱动状态转移：
  \[
  H = \bar{A} \hat{h} + \bar{B} x,\quad y = C H
  \]
- 采用连续时间状态空间模型（Mamba）的零阶保持（ZOH）离散化，将拓扑结构与视觉证据融合在统一状态中。
- 节点并行处理，保持置换等变性，避免顺序偏差。
- 引入可学习前馈矩阵 \(D\) 形成残差连接，得到最终 IGN 输出 \(Q_f = y + D x_0\)。

#### 2.4.3 上下文引导状态编码（CGSE）

- CGSE 从实例特征生成状态空间模型的关键矩阵 \(B\)、\(C\)、\(\Delta\)：
  - \(B\)、\(C\) 通过线性变换从细胞实例特征学习得到。
  - \(\Delta\) 使用 Softplus 激活，并采用低秩分解控制参数量。
- 状态转移矩阵 \(A\) 由 HiPPO-LegS 初始化，全局共享。

#### 2.4.4 预测与损失

- 融合特征 \(Q_f\) 送入分类头和回归头，分别预测类别和边界框。
- 使用匈牙利算法匹配预测与真值，总损失为：
  \[
  \mathcal{L} = \lambda_{\text{cls}}\mathcal{L}_{\text{cls}} + \lambda_{\text{bbox}}\mathcal{L}_{\text{bbox}} + \lambda_{\text{iou}}\mathcal{L}_{\text{iou}}
  \]
  其中 \(\mathcal{L}_{\text{cls}}\) 为 Focal Loss，\(\mathcal{L}_{\text{bbox}}\) 为 L1 Loss，\(\mathcal{L}_{\text{iou}}\) 为 GIoU Loss。
