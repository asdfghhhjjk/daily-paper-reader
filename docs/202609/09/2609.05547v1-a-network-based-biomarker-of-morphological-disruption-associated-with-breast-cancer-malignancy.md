## 摘要
乳腺癌诊断通常考虑单个细胞核形态特征，而较少评估它们的联合组织方式。我们开发了形态学网络紊乱指数（MNDI），一种相对于良性参考状态的患者水平形态异常度量。使用威斯康星诊断乳腺癌数据集，将十个细胞核特征表示为网络节点，MNDI总结了45对特征配置间的紊乱。性能通过重复分层五折交叉验证评估。恶性病变的MNDI显著高于良性病变（均值：3.454 对 1.165；p = 2.94e-69）。MNDI达到AUC 0.941（95% CI：0.918–0.961），灵敏度85.9%，特异度91.6%。使用网络衍生描述符的分类器达到AUC 0.928 ± 0.024。在BreaKHis组织病理学队列中的独立评估显示区分能力有限（AUC = 0.538，95% CI：0.401–0.668），表明其依赖于基础形态学表示。MNDI为量化患者特异性形态紊乱提供了一个可解释框架，但各实现需在兼容的特征空间内进行验证。

## Abstract
Breast cancer diagnosis commonly considers individual nuclear morphological characteristics, whereas their joint organization is less frequently evaluated. We developed the Morphological Network Disruption Index (MNDI), a patient-level measure of morphological abnormality relative to a benign reference state. Using the Wisconsin Diagnostic Breast Cancer dataset, ten nuclear characteristics were represented as network nodes, with MNDI summarizing disruption across 45 pairwise feature configurations. Performance was evaluated using repeated stratified five-fold cross-validation. Malignant lesions exhibited substantially higher MNDI than benign lesions (mean: 3.454 vs. 1.165; p = 2.94e-69). MNDI achieved an AUC of 0.941 (95% CI: 0.918-0.961), with 85.9% sensitivity and 91.6% specificity. A classifier using network-derived descriptors achieved an AUC of AUC of 0.928 +/- 0.024. Independent evaluation in the BreaKHis histopathology cohort showed limited discrimination (AUC = 0.538, 95% CI: 0.401-0.668), indicating dependence on the underlying morphological representation. MNDI provides an interpretable framework for quantifying patient-specific morphological disruption, while individual implementations require validation within compatible feature spaces.
