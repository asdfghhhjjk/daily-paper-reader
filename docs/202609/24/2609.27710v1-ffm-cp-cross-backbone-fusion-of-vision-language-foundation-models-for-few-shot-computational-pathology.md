## 摘要
病理视觉-语言基础模型在不同疾病和任务上的性能表现不一，没有任何单一模型能始终表现最佳。专家病理标注的高昂成本也可能限制可用于任务特定适配的标注数据。结合互补的预训练表示是应对这些局限的一种潜在方法，但从少量标注样本中学习有效融合仍具挑战性。我们提出少样本计算病理学融合基础模型（FFM-CP），这是一个在少样本学习设置下结合多个病理视觉-语言模型的框架。该框架首先利用由对应支持图像估计的闭式正交普鲁克变换对齐异构表示。这种对齐无需训练额外的对齐网络即可保持模型内特征几何。在对齐空间中，统一图通过联合细化支持图像特征以及视觉和文本类别原型，实现跨骨干的信息交换。这些细化表示支持互补的文本原型分支和病例检索分支，分别捕获语义类别知识和类内视觉变化。每个分支学习组合来自所有有序骨干对的预测，使得由一个模型编码的查询能够利用由另一个模型表示的证据。我们在六个组织病理学数据集上，以每类4、8和16个样本评估三种骨干组合。在54项比较中，FFM-CP在50项中取得了比各融合集合中最强单独适配成员更高的平均宏F1。这些发现表明，在标注有限时，结合互补的预训练表示能够改善组织病理学分类。

## Abstract
Pathology vision-language foundation models vary in performance across diseases and tasks, with no single model consistently performing best. The high cost of expert pathology annotation can also limit the labeled data available for task-specific adaptation. Combining complementary pretrained representations is a potential approach to these limitations, yet learning an effective fusion from few labeled examples remains challenging. We introduce Few-shot Fusion Foundation Models of Computational Pathology (FFM-CP), which is a framework that combines multiple pathology vision-language models in the few-shot learning setting. The framework first aligns heterogeneous representations using a closed-form Orthogonal Procrustes transformation estimated from corresponding support images. This alignment preserves within-model feature geometry without training an additional alignment network. Within the aligned space, a unified graph enables information exchange across backbones by jointly refining support-image features and visual and textual class prototypes. These refined representations support complementary text-prototype and case-retrieval branches that capture semantic class knowledge and within-class visual variation, respectively. Each branch learns to combine predictions from all ordered backbone pairs, allowing queries encoded by one model to draw on evidence represented by another. We evaluate three backbone combinations on six histopathology datasets at 4, 8, and 16 shots per class. FFM-CP achieves higher mean macro-F1 than the strongest individually adapted member of each fused set in 50 of 54 comparisons. These findings suggest that combining complementary pretrained representations can improve histopathological classification when annotations are limited.

  - 已有的多基础模型融合方法通常依赖数百甚至数千张标注样本，或需要额外的、独立的大规模蒸馏预训练阶段，难以直接用于仅 K 个标注 tile 的少样本设置。
- **整体含义**：该论文提出 FFM-CP，旨在解决“如何仅用少样本支持集，融合多个完整的、异构的病理视觉-语言基础模型，从而提升组织病理分类性能”这一尚未充分解决的问题。

## 2. 方法论

### 2.1 核心思想

- 将多个冻结的病理 VLM 视作互补的证据来源，在对齐后的共享空间中，通过统一图进行跨骨干信息交换，并用双分支对所有有序骨干对进行预测融合。
- 所有基础模型编码器保持冻结，仅学习任务特定的对齐、图传播和融合参数。

### 2.2 关键技术细节

- **跨骨干对齐（Orthogonal Procrustes, OP）**
  - 选择一个具有最大嵌入维度的模型作为参考模型，维度记为 \(d\)。
  - 对每个其他模型 \(m\)，利用对应支持图像特征解闭式正交普鲁克问题：
    \[
    Q_m = \arg\min_{Q^\top Q = I_{d_m}} \| Z_r^v - Z_m^v Q^\top \|_F^2 = U_m V_m^\top
    \]
    其中 \(U_m \Sigma_m V_m^\top\) 是交叉协方差 \(Z_r^{v\top} Z_m^v\) 的薄奇异值分解。
  - 该映射保持特征范数和模型内余弦相似度，无需训练额外对齐网络，且可从支持集直接估计。

- **统一知识图**
  - 节点包括三类：支持图像节点、视觉类别原型节点、文本类别原型节点，分别来自所有 \(M\) 个模型。
  - 七种关系：
    - 六种由特征相似度推导：\(E^{s\leftarrow t}\)、\(E^{s\leftarrow s}\)、\(E^{p\leftarrow t}\)、\(E^{p\leftarrow p}\)、\(E^{t\leftarrow p}\)、\(E^{t\leftarrow t}\)，计算公式为中心化相似度：
      \[
      [A^{a\leftarrow b}]_{ij} = \operatorname{sim}(X_i^a - \mu^a, X_j^b - \mu^b)
      \]
      同类关系去掉自环。
    - 一种由标签决定：\(E^{p\leftarrow s}\)，仅连接同类同骨干的支持图像到视觉原型，采用二进制邻接矩阵。

- **图学习与消息传递**
  - 按顺序细化三类特征：
    1. 支持图像特征从文本原型和其他支持图像聚合；
    2. 视觉原型从已细化的支持特征、文本原型和其他视觉原型聚合；
    3. 文本原型从已细化的视觉原型和其他文本原型聚合。
  - 每条关系由可学习标量 \(w_j\) 加权；目的地特定消息传递算子为：
    \[
    g_a(X, Y, A) = \sigma\left( D_X^{-1} X W_a^{\text{self}} + \hat{A} Y W_a^{\text{msg}} + b_a \right)
    \]
    其中 \(\hat{A}\) 为对称归一化邻接矩阵，\(W_a^{\text{self}}\)、\(W_a^{\text{msg}}\)、\(b_a\) 为可学习参数，\(\sigma\) 为激活函数。
  - 特征相似度关系可在跨骨干间传递，使得一个模型的文本/视觉表示能够被另一个模型的证据细化。

- **双分支预测融合**
  - 文本原型分支：利用语义类别知识。
  - 病例检索分支：比较查询与最相关支持样本，保留类内视觉变化。
  - 两个分支均学习组合所有 \(M^2\) 个有序查询-证据模型对的预测，允许由一个模型编码的查询使用由另一个模型表示的证据。

- **训练目标**
  - 融合损失：
    \[
    \mathcal{L}_{\text{fuse}} = \frac{1}{N}\sum_{i=1}^N \left[ \text{CE}(\ell_t(x_i), y_i) + \lambda \text{CE}(\ell_c(x_i), y_i) \right]
    \]
  - 对角辅助损失：保持同模型内部文本/病例分类能力。
  - 总损失：
    \[
    \mathcal{L} = \mathcal{L}_{\text{fuse}} + \eta \mathcal{L}_{\text{diag}}
    \]
  - 推理时对两个分支的融合 logits 分别 softmax 后取平均，得到最终类别概率。

## 3. 实验设计

### 3.1 数据集与场景

- 六个公开组织病理数据集：

  - **HeidelbergSkin**：皮肤，16 类，129,369 个 tile。
  - **Kather2016**：结直肠，8 类，5,000 张图像。
  - **LubLung**：肺，9 类，23,199 个 tile。
  - **BRACS**：乳腺，7 类，4,539 个 ROI。
  - **BACH**：乳腺，4 类，400 张图像。
- 覆盖 4 个器官、组织类型识别与诊断亚型分类，规模和类别数差异大。

### 3.2 评估协议

- 少样本设置：每类 4、8、16 个支持样本（shot）。
- 每个数据集划分为训练、验证、测试；从训练分区抽取支持集，验证集每类抽取 \(\min(K,4)\) 个样本。
- BRACS 使用官方发布测试集，不额外修改。
- 每次实验重复 5 个随机种子，报告均值±标准差，宏 F1 为主要指标；附录中报告 ACC、AUC。

## 6. 主要结论与发现

- 在 54 项比较中，FFM-CP 在 50 项上超过对应融合集合中表现最强的单体模型；4-shot 下 14/18 项提升，8-shot 和 16-shot 下全部 18 项提升。
- 平均宏 F1 增益分别为：4-shot +2.35 个百分点，8-shot +3.12 个百分点，16-shot +3.73 个百分点。
- 即使某些骨干单体性能明显较弱，融合后仍可带来显著提升，说明不同骨干之间存在互补信息。
- OP 对齐比 zero-padding 或可训练 MLP 更有效，证明从成对支持图像中拟合跨骨干对应关系是有价值的。
- 跨骨干预测对整体有益，但收益因数据集而异，平均增益约 0.59 个百分点。

## 7. 优点

- **闭式对齐**：使用正交普鲁克变换，无需训练额外对齐网络，参数高效且可解释。
- **统一图设计**：将多模型的视觉、文本和支持特征联合细化，支持跨骨干信息交换，而非简单独立预测。
- **双分支融合**：同时利用语义类别知识和类内视觉变化，并覆盖所有有序骨干对。
- **冻结编码器**：所有 VLM 视觉和文本编码器固定，仅学习轻量适配与融合组件，适合少样本场景。
- **实验设置规范**：多数据集、多 shot、多种子，结果报告透明。

## 8. 不足与局限

- **任务范围有限**：实验仅覆盖 tile/region 级分类，未涉及 whole-slide image（WSI）分类或弱监督多实例学习。
